# Autonomous-underwater-vehicle-positioning-control-a-velocity-form-LPV-MPC-approach
The velocity-form LPV-MPC algorithm implemented in this MATLAB code leverages the interconnection between the kinematic and dynamic models of marine vehicles to mitigate steady-state tracking errors. This repository presents the implementation of the LPV-MPC positioning controller in the conference paper: 
Jimoh, I.A., Yue, H. and Küçükdemiral, I.B., 2023. Autonomous underwater vehicle positioning control-a velocity form LPV-MPC approach. _IFAC-PapersOnLine_, 56(2), pp.4388-4393.
